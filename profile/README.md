# unbought games

**Games worth playing. Victory worth earning.**

We're building open-source browser games without pay-to-win. We want to preserve
the strategy, competition, and communities that make these games worth playing,
with winning determined by how you play.

No purchased resources, faster queues, or stronger fleets. Gameplay tools and
conveniences should be available to everyone. Our games are open source so you
can inspect the rules, help improve them, and run your own server.

## Play Orbit Imperium

[Orbit Imperium](https://orbitimperium.com/) is our first game: a persistent
multiplayer space strategy game you can play in your browser. Develop planets,
research technologies, build fleets, raid your neighbors, and form alliances.

It's in **open beta**. The game is incomplete, and the official universe may be
reset before the full public launch.

before you build it.
